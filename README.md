# 青空パズル

青空文庫の一場面を、紙片から原文の順序へつなぎ直すブラウザゲーム。作品を読んだ記憶や、言葉・情景のつながりを頼りに、共通の3ライフで何問読み通せるかに挑みます。

## 遊び方

一枚の案内紙から『吾輩は猫である』4問、『檸檬』7問、『銀河鉄道の夜』4問のどれかを選びます。選んだ作品の抜粋が、重複しないランダム順で出ます。設定の「ふつう」「細かめ」は同じ文章を意味のある違う紙片に分けます。初読・時間制限・ランキングはありません。

- ドラッグで近づけて離すか、紙片を選んで相手の端をタップして仮組みします。正誤による接続音・色の違いや、正解のロックはありません
- 切れ目で分離、「元に戻す」で直前の配置操作を取り消せます。全部つながってから「読み通す」で提出します
- 正しい先頭部分を朗読し、最初に原文と違う紙片の直前で止まります。停止位置を見せてからライフが1減り、その先を未判定の塊として切り離します。塊の内部の順序は残ります
- 正解なら短い余韻の後、クリア数が増えます。「次の問題」で未出題の抜粋へ。全問クリアで作品踏破、ライフ0で終了です
- ヒントは挑戦全体で1回。選んだ塊の末尾に続く紙片を示し、自動接続しません。取消・表示できない続き・同じヒントの再表示は無料。次問・Undo・中断で回復しません

原文と出典は挑戦を終えてから読み返せます。最後に途切れた抜粋は、任意の「続きを聴く」で少し手前から末尾まで聴けます。意味の通る別の並びを日本語の誤りとするのではなく、原文の順序を復元する遊びです。

余白をドラッグして移動、ホイール・二本指で拡大縮小。ヒント欄の「見る」を押したとき以外、ヒントでカメラは動きません。通常の操作部は上下各52pxです。設定で男女の合成音声、音量・消音・動きの軽減を選べます。再提出では前に確認できた先頭部分だけを任意で早送りできます。

## 中断と保存

盤面、出題順、ライフ、クリア数、ヒント消費、提出済みの判定をこのブラウザのlocalStorageへ保存します。提出は音声再生の前に一度だけ記録され、通常の再読み込みで消費が戻ったり二重に減ったりしません。中断は終了と別で、原文・出典を開放しません。保存できない環境では警告します。別タブの更新を検出した場合は新しい状態から再開します。クラウド同期や改ざん防止の仕組みではありません。

以前に取り込んだ本のIndexedDBは読み取り専用のままです。設定の「保存した本」から確認できます。新規取り込み・再取り込み・保存済み本文の出題は引き続き休止し、削除・上書き・移行はしません。

## 開発

Node.js 22を使用します。

```sh
npm ci
npm run dev        # http://localhost:5678
npm test           # Node標準の小さな状態・本文・音声時刻テスト
npm run lint
npm run typecheck
npm run build
npm start
```

初回のdev/buildで、ロック済みFontsourceから書体と字形範囲表をpublic/fontsへ生成します。フォントのバイナリはGit管理しません。現在の遊びに作品APIは不要です。AOZORA_API_BASE_URLは休止中の取り込み処理用で、設定しても取り込みは再開しません。

## 構成

- src/game/run.ts：有限ラン、共通の消費、提出の確定、中断復帰
- src/game/model.ts：描画に依存しない紙片・仮組み・Undo・先頭一致の判定
- src/game/DeskScene.ts：Phaserの机、入力、判定の演出と振り返り
- src/game/narration.ts：連続音声の範囲再生、安全な停止、視覚進行、非同期キャンセル
- src/game/paper.ts / layout.ts：原稿用紙、文字と紙片単位の印
- src/data/passages.ts：3作品・15問の原文、出典、通常／細かな分割、読み
- src/data/narration.ts：音声マスターと境界時刻、固定コミットの配信URL
- audio-assets/：事前生成した合成音声。Vercelへは含めずGitHubから配信

音声の生成・ライセンス・境界確認は[音声の扱い](docs/narration.md)、抜粋ごとの理由は[選定方針](docs/passage-curation.md)を参照してください。表示原文と発音指定は別にし、本文を現代仮名へ置き換えません。本文・音声は公開クライアントの素材なので、原文の表示制御は暗号化による秘匿ではありません。

旧スコア・回答送信API・署名トークン・暗号化短文の復号経路は復活させません。旧URL /play と /result はトップへ移動します。2026-10-02の仕様はIssues #7〜#10と[ゲーム仕様](計画/青空パズル仕様書.md)に対応します。検証した内容と未確認の聴感・実機事項はPRの説明に短く記録し、重いブラウザCIやスクリーンショットの蓄積はしません。

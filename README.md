# 青空パズル

ばらばらになった青空文庫の一場面を、言葉の意味からつなぎ直すブラウザゲーム。
原文を先に覚えるのではなく、情景が読み取れる並びを自分で探します。

## 遊び方

一枚の案内紙から、3作品のどれかを選びます。『吾輩は猫である』4問、『檸檬』7問、『銀河鉄道の夜』4問の計15問があり、開始時に選んだ作品の中からランダムで出題します。同じ作品の直前の問題は続けて出しません。難易度選択や初読はありません。同じ机に広がる8〜12枚の意味のある紙片を、好きな場所から前後へつないでください。

ドラッグで近づけて離すか、紙片を選んで相手の端をタップします。接続はすべて仮組みで、正誤による色・音の違いや確定ロックはありません。切れ目を外すことも、「元に戻す」で操作を取り消すこともできます。

全部が一つにつながったら「読み通す」。原文と一致したときだけ完成し、元の原稿と出典を開きます。一致しなくても配置はそのまま残り、違う箇所や正しい継ぎ目は教えません。「ヒント」を押して紙片を選ぶと、その続きだけが黄色く光ります。つないだ塊は末尾の紙片が対象で、自動ではつなぎません。選んだ一片には緑の下線が残り、カメラは動きません。開閉できる画面下の欄に選んだ一片の末尾と続きの冒頭を表示し、それぞれの「見る」を押したときだけ、文字の大きさを保って必要な分だけ移動します。欄を閉じても選択元と続きの印は残り、再表示できます。押した紙片が欄に隠れる場合は、閉じた状態でヒントを表示します。一問につき3回。取消、表示できる続きがない場合、同じ紙片の再表示は回数を減らしません。元に戻しても回数は回復せず、「次の問題」や作品選択から新しく始めたときだけ3回に戻ります。遊び方の「読む手掛かり」は従来の意味の手掛かりです。完成前には原文や出典リンクを見せません。

机の余白をドラッグして移動、ホイール・二本指で拡大縮小。端に置いた小さな操作とキーボード・読み上げ用ボタンは、同じゲーム状態を操作します。

## 保存した本について

以前に取り込んだ本は一覧で確認できますが、この版では新しい取り込み・再取り込み・保存済み本文の出題を休止しています。今回の遊びは、人が場面と意味の切れ目を選んだ3作品・計15問に限定するためです。

既存のIndexedDBは読み取り専用で扱い、削除・上書き・移行しません。別の文章への黙った差し替えも行いません。原典処理・取り込みのユーティリティは将来のために残しますが、現行の遊びからは呼び出しません。

## 開発

Node.js 22を使用します。

```sh
npm ci
npm run dev        # http://localhost:5678
npm test           # Node標準の小さなルール・原文検査
npm run lint
npm run typecheck
npm run build
npm start
```

初回のdev/buildで、ロック済みのFontsourceパッケージから書体と字形範囲表を`public/fonts/`へ生成します。ブラウザから外部フォントCDNへは接続しません。生成物はGit管理しません。

選定問題で遊ぶために作品APIは不要です。`AOZORA_API_BASE_URL`は休止中の取り込み処理用の設定であり、設定しても現在の取り込み休止は解除されません。

## 構成

- `src/game/model.ts`：ゲーム状態とコマンド。描画・React・通信には依存しません。`makeProblem`は`curatedVersion: 1`の選定原稿だけを受け入れ、`Problem` v3を生成します。
- `src/game/questions.ts`：作品内のランダム出題と直前問題の除外。
- `src/game/hint-context.ts`：ヒントの文脈表示と、明示操作時だけの最小カメラ移動。
- `src/game/DeskScene.ts`：Phaserの画面、入力、カメラ、セッション所有者。
- `src/game/layout.ts` / `paper.ts`：原稿用紙の文字配置と描画。
- `src/components/GameHost.tsx`：Canvasの寿命と読み上げ用の状態投影。
- `src/data/passages.ts`：原文・出典・抜粋位置・意味の分割・手掛かりを持つ3作品・計15問。
- `src/lib/aozora.ts` / `books.ts`：休止中の取り込み処理と既存保存形式の読み取り。

旧スコア・回答送信API・署名トークン・暗号化短文の復号経路は復活させません。`/play`と`/result`の旧URLはトップへ移動します。

## 抜粋の選定

『檸檬』には、冒頭の不吉な塊、見すぼらしくて美しい街、花火とびいどろの記憶を加えました。既存の買物・冷たさ・香り・本の城も残しています。全作品の実際の本文位置と選定理由は[抜粋位置の記録](docs/passage-curation.md)を参照してください。

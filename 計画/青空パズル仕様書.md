# 青空パズル仕様 — 一場面をつなぐ

2026-10-01 / 第2再設計 / `Problem` v3。初読・難易度別の確定枚数・部分正解のロックを採用したv2仕様を置き換える。Draft PR #6の更新範囲とし、マージ・本番デプロイは含めない。

## 体験と進行

一枚の案内紙で場面を選ぶ → 同じ机に紙片が広がる → 意味を読みながら自由に仮組みする → 全体を「読み通す」 → 完成した原稿と出典を読む。

遊べるのは人が編集した3場面。各場面を8〜12枚の意味のあるまとまりに分ける。原文の初読、難易度選択、時間制限、ライフ、スコア、ランキングは設けない。完成前には原文、全文プレビュー、出典リンクへの導線を出さない。

先頭に限らず好きな場所から、紙片や塊を相手の前後へつなぐ。接続はすべて仮組み。正しい接続でも誤った接続でも、音・色・形・通知は同じであり、正誤の事前判定も部分確定も行わない。すべての継ぎ目を分離できる。

全紙片が一つの塊になった後だけ「読み通す」を使える。明示操作で、その並びの文字列が比較用原文と完全一致するか確認する。最後の紙片を接続しただけでは完成しない。不一致なら配置も履歴も保持し、正しい箇所・誤った継ぎ目・近さを教えず、組み直せる。意味の通る別解を言語エンジンで採点する方式にはしない。

ヒントは場面ごとに作成した意味の手掛かりで、何度でも開ける。人物、時間、場所、動作、気持ちのつながりに目を向け、特定の紙片の前後関係や正しい継ぎ目を答えない。

Undoは直前64操作の状態と座標を保持する。移動・接続・分離・完成確認を戻せる。座標だけの移動も一操作で、ドラッグの各フレームや不一致の確認は履歴を消費しない。

## 状態と責務

`Session`を唯一のゲーム状態とし、PhaserのSceneが所有する。紙片IDはランダムで、原文の位置を含まない。同じ文字列の紙片は交換可能。継ぎ目情報は表示と分離のためだけに使い、正解ロックを持たない。

ドラッグ中の仮座標、選択、カメラ、音、Tweenは表示側の状態。接続は明示的なドロップまたは選択後の端タップで行う。近傍通過・ホバー・接続時に原文へ照会しない。

Reactは読み取り専用スナップショットをアクセシビリティへ投影する。読み上げ用ボタンも同じSceneコマンドを呼ぶ。初期化の内部状態名が`reading`でも初読画面を意味しない。完成前にはDOM・読み上げ通知にも原文や出典リンクを投影しない。

## 原稿の編集

`src/data/passages.ts`に原文、出典、抜粋位置、場面名、短い導入、手作業の分割、意味のヒントを記録する。`curatedVersion: 1`の選定原稿だけが`makeProblem`の対象となり、`Problem` v3を生成する。8〜12枚であることと原文一致は開始時にも検査する。

紙片は助詞や単語を機械的に刻まず、一つの意味を読める単位にする。自然に交換できて原文の順序を推測できない箇所は、分割や抜粋の選び直しで減らす。正しさと面白さは編集で支え、形態素・文法エンジンや言語モデルの判定を追加しない。

表示上の原文と比較文字列を分ける。比較ではCRLFを改行に統一し、段落頭の字下げと改行を除く。NFKC、現代仮名への変換、句読点削除、一般空白の一括削除は行わない。文字数合わせの継ぎ足しや代替文章は使わない。

## 保存と確認

以前の保存済み作品は読み取り専用で一覧に残す。新規取り込み・再取り込み・保存済み抜粋からの出題は休止理由を明示する。既存レコードの削除・置換・移行は行わず、旧データを選定原稿へ黙って変換しない。

少数のルールテスト、本番ビルド、実ブラウザの代表操作で検証する。部分正誤が漏れないこと、明示的な全文確認、不一致後の配置保持、ヒント・分離・Undo、完成前の原文非表示、保存の非変更を重点にする。人による読みやすさ・聴感・推理する面白さと、機械検証の成功を分けて`docs/verification.md`へ記録する。

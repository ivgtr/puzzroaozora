# 青空パズル仕様 — 共通ライフで読み通す

2026-10-02 / Issues #7–10。従来の一問完結・ヒント3回・正解直後の出典公開を置き換える。初読と部分接続の正解ロックは復活させない。

## 一回の挑戦

作品を選ぶ → 未出題の抜粋を組む → 「読み通す」 → 正解なら次問、誤答なら同じ盤面を直す → 全問クリアまたはライフ0で結果 → 任意の原文・出典・朗読の振り返り。

現在の収録は3作品・15問（4/7/4）。任意の作品取り込みは廃止し、原文・分割・朗読を確認した選定作品を開発側で追加する。選択した作品の全問を最初にランダムな有限順へ並べ、同じ抜粋を再出題しない。共通ライフ3、回復なし、ヒント1回は初版の調整値。結果は今回のクリア数／作品の全問数と紙片の細かさを示し、問題数が異なる作品を単純な得点で比較しない。時間制限、ランキング、恒久履歴は追加しない。

全紙片を一つにした提出だけが判定される。仮組み、分離、移動は正誤を示さない。正しい先頭の紙片までは連続音声で読み、最初に違う紙片へ入る前に止まる。先頭から違えば原文冒頭を読まず、その紙片に停止位置を示す。少し間を置いてライフを減らし、未判定の後半を内部順を保った塊として分離する。意味の通る別順序を日本語として誤りとは扱わず、原文の順序を目指す。

正解は最終文字まで読んでから紙が整い、短い音、クリア数の増加へ進む。次問は明示操作で開始し、余韻を急かさない。最終問は作品踏破の結果へ。残り1ライフは数字の控えめな色・状態文で伝え、常時点滅や鼓動音は使わない。

## 状態と中断

`Run`が出題順・消費・提出を所有し、現在の`Session`が紙片と配置を所有する。提出時に結果を一度だけ記録し編集をロック、音声・演出終了時に保存済みの結果をsettleする。音声の失敗や重複コールバックがライフ計算を行わない。未settleの提出は中断後も同じ結果として再開する。

Undoは配置操作だけを対象とし、提出をまたがない。正解数やヒント消費もUndo履歴と別に保持する。localStorageへ盤面、紙片ID、出題順、消費、提出結果を版付きで保存し、復帰時に現在の選定原文と突き合わせる。別タブの新しい状態は古い保存で上書きせず、再開を案内する。既存の本のIndexedDBは変更しない。

中断は結果公開ではない。明示した「挑戦を終える」は終了となり、今回挑戦した抜粋を振り返れる。新しい挑戦だけでライフとヒントを補充する。保存失敗・不正な保存形式は理由を表示し、別の本文へ黙って置き換えない。

## ヒントと振り返り

選んだ紙片／塊の末尾の、原文での続きだけを表示する。自動接続も塊全体の判定もしない。ヒントの取消、続きがない／一意でない対象、同じ対象の再表示は無料。次問・Undo・再開では補充しない。意味の助言は「遊び方 → 読む手掛かり」に残す。

正解後に表示するのは組み立てた文章で、原文パネルや出典を開放しない。終了後に挑戦した抜粋の原文と出典を読める。最終失敗の「続きを聴く」は停止位置の一つ手前から末尾までを任意再生し、停止・読み返し・新しい挑戦へ進める。未出題の原文や作品全文の自動朗読には広げない。

## 音声と内容

表示原文・比較文・発音指定を分ける。通常と細かめは同じ短い抜粋・マスターを共有。意味がまとまり、場面や語句の記憶が効く分割を手で選び、朗読20〜25秒は柔らかな目安にする。紙片の数のために不自然な細切れや音声停止を増やさない。

Irodori-TTS-v4.1-Smallの男女の合成音声を事前生成する。連続マスターと既知の読み・実音声に対応する境界時刻を使い、誤答時に次の語へ入らない。安全に切れない境界は編集・再生成で修正し、未確認な切断は音声を流さず明示した視覚進行へ。全区間の機械確認と、人が聴いた自然さは別に記録する。

消音でも読む位置→停止→減算／成功の順は保つ。前の提出で正しかった先頭だけを任意で早送りでき、編集して変わった部分は飛ばさない。端末で音声が使えなくても追加減算せず進む。動きの軽減は印中心にする。

## 検証

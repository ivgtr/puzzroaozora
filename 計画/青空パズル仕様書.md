# 青空パズル（Aozora Puzzle）仕様書

## 1. システム概要

### 1.1 プロジェクト名
青空パズル（Aozora Puzzle）

### 1.2 システム概要
青空文庫の文学作品から抜粋したテキストを形態素解析により分割し、ランダムに並び替えたものを正しい順序に並べ直すパズルゲーム。

### 1.3 主要機能
- 青空文庫からの作品データ取得
- 形態素解析によるテキスト分割
- パズルゲームのインタラクティブUI
- 解答の正誤判定
- スコアリング機能

## 2. アーキテクチャ

### 2.1 システム構成
```
クライアント（Next.js Pages Router）
    ↓ GET（キャッシュ可能）
サーバー（Next.js API Routes）
    ↓ 
青空文庫API / 形態素解析処理
```

### 2.2 技術スタック
- **フロントエンド**: Next.js (Pages Router), React, TypeScript, Tailwind CSS v4
- **バックエンド**: Next.js API Routes
- **形態素解析**: kuromoji.js（ブラウザ・Node.js両対応）
- **外部API**: 青空文庫API
- **開発環境**: localhost:5678

## 3. データモデル

### 3.1 パズルデータ構造

```typescript
// パズル問題データ
interface PuzzleData {
  id: string;                    // パズルの一意識別子（UUID v4）
  bookId: number;                 // 青空文庫の作品ID
  title: string;                  // 作品タイトル
  author: string;                 // 著者名
  originalText: string;           // 元のテキスト（一部抜粋）
  segments: PuzzleSegment[];      // 分割された形態素の配列
  shuffledSegments: PuzzleSegment[]; // シャッフルされた形態素配列
  difficulty: 'easy' | 'normal' | 'hard'; // 難易度
  textLength: number;             // テキストの文字数
  createdAt: string;              // ISO 8601形式の作成日時
}

// 形態素セグメント
interface PuzzleSegment {
  id: string;                     // セグメントの一意識別子
  text: string;                   // 形態素のテキスト
  position: number;               // 正解の位置（0から始まる）
  partOfSpeech: string;           // 品詞情報
  reading?: string;               // 読み仮名（オプション）
}

// 解答データ
interface AnswerData {
  puzzleId: string;               // パズルID
  userAnswer: string[];           // ユーザーが選択した順序（segment.id の配列）
  startedAt: string;              // 開始時刻（ISO 8601）
  submittedAt: string;            // 提出時刻（ISO 8601）
  timeSpent: number;              // 経過時間（秒）
}

// 判定結果
interface ResultData {
  puzzleId: string;
  isCorrect: boolean;             // 正解かどうか
  score: number;                  // スコア（0-100）
  correctPositions: number;       // 正しい位置にある形態素の数
  totalSegments: number;          // 総形態素数
  timeBonusScore: number;         // 時間ボーナス
  feedback: string;               // フィードバックメッセージ
}
```

## 4. API仕様

### 4.1 パズル取得API

#### GET `/api/puzzle/generate`

**リクエストパラメータ（Query Parameters）**:
```typescript
{
  bookId?: number;       // 特定の作品ID（省略時はランダム）
  difficulty?: 'easy' | 'normal' | 'hard'; // 難易度（省略時は'normal'）
  seed?: string;         // シード値（同じシードで同じパズルを生成）
}
```

**レスポンス**:
```typescript
{
  success: boolean;
  data?: PuzzleData;
  error?: {
    code: string;
    message: string;
  };
}
```

**レスポンスヘッダー**:
```
Cache-Control: public, max-age=3600, s-maxage=86400
ETag: [パズルデータのハッシュ値]
```

### 4.2 解答提出API

#### POST `/api/puzzle/submit`

**リクエストボディ**:
```typescript
{
  answer: AnswerData;
}
```

**レスポンス**:
```typescript
{
  success: boolean;
  data?: ResultData;
  error?: {
    code: string;
    message: string;
  };
}
```

### 4.3 作品リスト取得API

#### GET `/api/books/list`

**リクエストパラメータ**:
```typescript
{
  limit?: number;        // 取得件数（デフォルト: 20）
  offset?: number;       // オフセット（ページネーション用）
  author?: string;       // 著者名でフィルタ
}
```

**レスポンス**:
```typescript
{
  success: boolean;
  data?: {
    books: Array<{
      id: number;
      title: string;
      author: string;
      kanaType: string;  // 文字遣い種別
    }>;
    total: number;
    hasMore: boolean;

}
```

## 5. ゲームフロー

### 5.1 基本フロー

1. **初期画面**
   - ゲーム説明の表示
   - 「スタート」ボタン
   - 難易度選択（easy/normal/hard）
   - 作品選択（オプション）

2. **パズル取得**
   - `/api/puzzle/generate` にGETリクエスト
   - ローディング表示
   - エラー時はリトライボタン表示

3. **ゲーム画面**
   - 上部：作品情報（タイトル、著者）
   - 中央上：選択済みエリア（ユーザーが並べた形態素）
   - 中央下：選択可能エリア（シャッフルされた形態素）
   - 右側：タイマー、ヒントボタン、リセットボタン

4. **形態素選択**
   - 選択可能エリアから形態素をクリック
   - 選択済みエリアに移動（アニメーション付き）
   - 選択済みの形態素をクリックで選択可能エリアに戻す
   - ドラッグ&ドロップによる並べ替え対応

5. **解答提出**
   - 全ての形態素を配置後「提出」ボタンが有効化
   - `/api/puzzle/submit` にPOSTリクエスト

6. **結果表示**
   - 正解/不正解の表示
   - スコア表示
   - 正解テキストの表示
   - 「もう一度」「次の問題」ボタン

### 5.2 UI/UX要件

#### 形態素の表示
- 各形態素は独立したカード/チップとして表示
- 品詞によって色分け（名詞：青、動詞：緑、助詞：グレー等）
- ホバー時に読み仮名をツールチップ表示
- 選択時にハイライト効果

#### アニメーション
- 形態素移動時：スムーズなトランジション（200ms）
- 正解時：成功エフェクト（緑のフラッシュ等）
- 不正解時：エラーエフェクト（赤い振動等）

#### レスポンシブ対応
- モバイル：タッチ操作対応、縦向き最適化
- タブレット：横向き対応、ドラッグ&ドロップ
- デスクトップ：キーボードショートカット対応

## 6. 難易度設計

### 6.1 難易度の基本設計思想

難易度が上がるほど：
- 元テキストが短くなる（文脈から推測しにくくなる）
- 形態素の分割単位が細かくなる（パズルピースが増える）
- 品詞情報などのヒントが減る

### 6.2 各難易度の詳細設定

#### EASY（簡単）
```typescript
{
  textLength: 80-120,           // 元テキストの文字数（長め）
  segmentCount: 8-12,           // 形態素数（少なめ）
  tokenizationRules: {
    // 大きな単位で分割
    mergePatterns: [
      { pattern: ['名詞', '助詞'], maxLength: 10 },  // 「太郎は」
      { pattern: ['動詞', '助動詞'], maxLength: 8 }, // 「行きました」
      { pattern: ['形容詞', '助動詞'], maxLength: 8 },
      { pattern: ['副詞', '助詞'], maxLength: 6 },
    ],
    // 句読点は前の形態素と結合
    mergePunctuation: true,
    // 助詞の連続は結合
    mergeConsecutiveParticles: true,
  },
  hints: {
    showPartOfSpeech: true,     // 品詞表示あり
    showReading: true,           // 読み仮名表示あり
    colorCodeByPos: true,        // 品詞による色分けあり
    firstSegmentRevealed: true,  // 最初の1つは正解位置に配置済み
  },
  scoring: {
    baseScore: 50,               // 基礎点
    timeBonus: 30,               // 時間ボーナス最大値
    perfectBonus: 20,            // 完全正解ボーナス
  }
}
```

#### NORMAL（普通）
```typescript
{
  textLength: 50-80,            // 元テキストの文字数（中程度）
  segmentCount: 12-18,          // 形態素数（中程度）
  tokenizationRules: {
    // 標準的な単位で分割
    mergePatterns: [
      { pattern: ['名詞', '接尾'], maxLength: 6 },   // 「太郎さん」
      { pattern: ['動詞', '助動詞'], maxLength: 5 }, // 「行った」
    ],
    // 句読点は独立
    mergePunctuation: false,
    // 一部の助詞のみ結合
    mergeConsecutiveParticles: false,
    mergeCommonParticles: ['の', 'を'],  // よく使う助詞のみ前後と結合
  },
  hints: {
    showPartOfSpeech: true,      // 品詞表示あり
    showReading: false,          // 読み仮名表示なし
    colorCodeByPos: true,        // 品詞による色分けあり
    firstSegmentRevealed: false, // 最初から全てシャッフル
  },
  scoring: {
    baseScore: 70,               // 基礎点
    timeBonus: 50,               // 時間ボーナス最大値
    perfectBonus: 30,            // 完全正解ボーナス
  }
}
```

#### HARD（難しい）
```typescript
{
  textLength: 30-50,            // 元テキストの文字数（短め）
  segmentCount: 15-25,          // 形態素数（多め）
  tokenizationRules: {
    // 細かい単位で分割
    mergePatterns: [],           // 結合なし、最小単位で分割
    mergePunctuation: false,
    mergeConsecutiveParticles: false,
    // 一文字の助詞も独立させる
    singleCharacterAsToken: true,
  },
  hints: {
    showPartOfSpeech: false,     // 品詞表示なし
    showReading: false,          // 読み仮名表示なし
    colorCodeByPos: false,       // 色分けなし（全て同じ色）
    firstSegmentRevealed: false, // 最初から全てシャッフル
  },
  scoring: {
    baseScore: 100,              // 基礎点
    timeBonus: 80,               // 時間ボーナス最大値
    perfectBonus: 50,            // 完全正解ボーナス
  }
}
```

#### EXPERT（エキスパート）※将来実装
```typescript
{
  textLength: 20-30,            // 元テキストの文字数（とても短い）
  segmentCount: 20-30,          // 形態素数（とても多い）
  tokenizationRules: {
    // 文字レベルまで分割する可能性
    characterLevelSplit: true,   // 漢字を1文字ずつに分割
    splitCompoundWords: true,    // 複合語を分解
  },
  hints: {
    showPartOfSpeech: false,
    showReading: false,
    colorCodeByPos: false,
    firstSegmentRevealed: false,
    // 誤った選択肢を混ぜる
    includeDummySegments: 2-3,   // ダミーの形態素を追加
  },
  scoring: {
    baseScore: 150,

  }
}
```

## 7. 形態素解析処理

### 7.1 処理フロー

1. **テキスト抽出**
   - 青空文庫から取得したテキストから難易度に応じた長さを抽出
   - ルビ、注釈の除去
   - 改行・空白の正規化

2. **形態素解析**
   - kuromoji.jsを使用
   - 品詞情報、読み仮名を取得
   - 難易度に応じた分割ルールを適用

3. **シャッフル処理**
   - Fisher-Yatesアルゴリズムでランダム化
   - シード値対応で再現可能

### 7.2 形態素の扱い

```typescript
// 形態素解析の設定
interface TokenizerConfig {
  // 統合する品詞の組み合わせ
  mergeRules: Array<{
    patterns: string[];      // 品詞パターン
    maxLength: number;       // 最大統合文字数
  }>;
  
  // 除外する品詞
  excludePos: string[];
  
  // 最小形態素長
  minTokenLength: number;
}
```

### 8.1 エラーコード体系

```typescript
  INVALID_ANSWER_FORMAT = 'E301',

  RATE_LIMIT_EXCEEDED = 'E429',
```

### 8.2 リトライ戦略

- API通信失敗時：最大3回リトライ（指数バックオフ）
- 青空文庫API失敗時：代替テキストソースを使用
- 形態素解析失敗時：フォールバック辞書を使用

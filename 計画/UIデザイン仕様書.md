# 原稿用紙と作業台のUI

2026-10-02 / 共通ライフ・朗読の進行。2026-10-01の紙と操作感を維持し、結果・保存・音声の導線を更新する。

正式名称は「青空パズル」。灰緑の机、生成りの紙、控えめな赤茶の方眼、墨色の文字。入口は一枚の案内紙で3作品を選び、作品の問題数を示す。プレビュー本文、問題一覧、本棚、ダッシュボードは置かない。難しさは設定の「紙片の細かさ：ふつう／細かめ」で次の挑戦から選ぶ。

通常の固定操作は上下52pxの各一列、操作域44px。上は名前・残ライフ・今回のクリア数、全体表示・設定。下はUndo／遊び方、提出できるときの「読み通す」、共通ヒント残数。文脈・エラー欄は必要なときだけ52pxを追加する。欄の開閉は見ていた紙片を動かさず、入力と描画で同じ作業面を使う。

本文はNoto Serif JP Medium 22px、29pxの方眼、紙端14px。UIはNoto Sans JP。grapheme、禁則、ASCII半マス、原文改行を維持する。フォントの字形を読み込んでから描画し、未対応字形や失敗を黙って代替しない。紙模様・切り口・IDは原文順を示さない。

接続は全て同じ仮組みの反応。ドラッグ／端タップ、任意の切れ目の分離、Undoを保つ。二本指、取消、画面外の解放では未確定移動を戻す。ヒントの選択元を下線、後続を淡い色で残し、欄の明示した「見る」以外で勝手にカメラを飛ばさない。

## 読み通す

提出中は編集を止め、読んでいる紙片に下線、確認済みの先頭に落ち着いた印を出す。文章は連続して読み、紙片ごとの効果音や大きな揺れを挟まない。カメラは自動追従しない。全体表示やパンで自分で位置を調整できる。

誤答は最初の不一致の前で止まり、停止印→短い間→ライフ減少→未判定の後半の分離。先頭不一致も冒頭の正解を漏らさず見える停止印から進める。後半内部の正しさは示さない。残り1は控えめな数字の色と読み上げ状態で伝える。

正解は読み終える→短い余韻→継ぎ目がなじんだ組み立て文→終止音→クリア数の順。大きな成功文字・紙吹雪で文章を隠さない。通常は短く、最後のライフや踏破で少し余韻を長くする。次問は明示操作。原文パネルと出典は終了まで出さない。

## 終了・設定・中断

終了は作品とクリア数／全問数を主役にし、任意の「続きを聴く」「読み返す」「もう一度挑む」「作品を選ぶ」を示す。振り返りは今回挑戦した抜粋だけ。原文、出典、前後移動、朗読の再生停止を用意し、長い朗読を強制しない。

設定は音量・消音、女性／男性、動きの軽減。作品・難しさも確認できる。保存した旧作品の一覧は設定から引き続き開ける。中断は盤面と消費を保存して選択へ戻り、「再開」で同じ挑戦を続ける。「挑戦を終える」は別の明示操作。保存できない環境は画面とアクセシビリティへ警告する。

Reactは同じPhaser状態のアクセシビリティ投影だけ。判定中・終了後のモードと残数を文章で伝え、色・音だけに依存しない。未解答の原文・出典をDOMへ追加しない。音声は既存WebAudio contextを使い、破棄・新しい再生・退出では非同期処理と音声を停止する。マウントごとに一つのゲームを維持する。

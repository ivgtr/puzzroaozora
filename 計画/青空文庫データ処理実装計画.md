# 青空文庫データ処理実装計画

## 1. 青空文庫のテキスト形式について

### 1.1 青空文庫の注記形式

青空文庫では独自の注記形式を使用しており、これらを適切に処理する必要がある。

#### 主要な注記形式

```
《》  - ルビ（振り仮名）
     例：吾輩《わがはい》は猫《ねこ》である

｜   - ルビの開始位置指定
     例：｜吾輩は猫《わがはいはねこ》である

［］  - 注記・注釈
     例：［＃「吾輩」に傍点］
     例：［＃ここから３字下げ］

※    - 編集者注
     例：※［＃「※」は「くさかんむり／欠」、第3水準1-91-52］

｜《》 - 外字・特殊文字
     例：※［＃「木＋神」、第3水準1-85-67］

――  - ダッシュ
     例：それは――誰も知らない

……  - 三点リーダー
     例：そして……

〔〕  - 編集者による補記
     例：〔後略〕

底本： - 底本情報（ファイル末尾）
```

### 1.2 処理が必要な特殊記法

#### 傍点・圏点
```
［＃「○○」に傍点］      - 傍点の指定
［＃「○○」に丸傍点］    - 丸傍点の指定
［＃「○○」に白ゴマ傍点］ - 白ゴマ傍点の指定
［＃「○○」に黒三角傍点］ - 黒三角傍点の指定
［＃「○○」に二重丸傍点］ - 二重丸傍点の指定
［＃傍点］○○［＃傍点終わり］ - 範囲指定
```

#### 字下げ・字上げ
```
［＃ここから○字下げ］
［＃ここで字下げ終わり］
［＃天から○字下げ］
［＃地から○字上げ］
［＃○字下げ］
```

#### 文字サイズ・字体
```
［＃「○○」は太字］
［＃「○○」は斜体］
［＃「○○」は大見出し］
［＃「○○」は中見出し］
［＃「○○」は小見出し］
［＃ここから○ポイント文字］
［＃ここで○ポイント文字終わり］
```

#### ページ・改行
```
［＃改ページ］
［＃改丁］
［＃改段］
［＃ページの左右中央］
```

## 2. データ取得方法

### 2.1 青空文庫API

#### 公式APIは存在しない
青空文庫には公式APIが存在しないため、以下の選択肢がある：

1. **青空文庫のGitHubリポジトリを使用**
   - https://github.com/aozorabunko/aozorabunko
   - 全作品のテキストファイルがGitHubで公開されている
   - Raw URLから直接テキストを取得可能

2. **非公式APIを使用**
   - Bunko API（https://bunko.ml/）※サービス終了の可能性あり
   - 青空文庫API（個人開発）など

3. **スクレイピング**
   - 青空文庫の公式サイトから直接取得
   - robots.txtの確認と負荷軽減が必要

4. **事前ダウンロード方式**
   - 人気作品を事前にダウンロードして保存
   - APIサーバー側でキャッシュとして保持

### 3.1 パーサーのアーキテクチャ

```typescript
// パーサーのパイプライン設計
interface ParserPipeline {
  stages: [
    'raw',           // 生のテキスト
    'normalized',    // 正規化（文字コード、改行）
    'cleaned',       // 注記の除去・変換
    'extracted',     // 本文の抽出
    'formatted'      // 最終形式
  ];
}

class AozoraParser {
  private pipeline: ParserStage[] = [
    new NormalizationStage(),
    new RubyProcessingStage(),
    new AnnotationRemovalStage(),
    new TextExtractionStage(),
    new FormattingStage()
  ];
  
  parse(rawText: string): ParsedText {
    return this.pipeline.reduce(
      (text, stage) => stage.process(text),
      rawText
    );
  }
}
```

### 3.2 各処理ステージの詳細

#### ステージ1: 正規化（Normalization）

```typescript
class NormalizationStage {
  process(text: string): string {
    return text
      // 文字コードの正規化（全角・半角）
      .replace(/[！-～]/g, (s) => String.fromCharCode(s.charCodeAt(0) - 0xFEE0))
      // 改行コードの統一
      .replace(/\r\n/g, '\n')
      .replace(/\r/g, '\n')
      // 連続する空白・改行の処理
      .replace(/\n{3,}/g, '\n\n')
      .replace(/　{2,}/g, '　')
      // 特殊な空白文字の正規化
      .replace(/[\u3000\u00A0]/g, ' ');
  }
}
```

#### ステージ2: ルビ処理（Ruby Processing）

```typescript
class RubyProcessingStage {
  process(text: string): ProcessedText {
    const rubyData: RubyAnnotation[] = [];
    
    // パターン1: 漢字《かな》形式
    let processed = text.replace(
      /([一-龠々]+)《([ぁ-ゔァ-ヴー]+)》/g,
      (match, kanji, kana, offset) => {
        rubyData.push({
          text: kanji,
          reading: kana,
          position: offset
        });
        return kanji; // ルビを除去して漢字のみ残す
      }
    );
    
    // パターン2: ｜漢字《かな》形式
    processed = processed.replace(
      /｜([^《]+)《([ぁ-ゔァ-ヴー]+)》/g,
      (match, text, kana, offset) => {
        rubyData.push({
          text: text,
          reading: kana,
          position: offset
        });
        return text;
      }
    );
    
    return {
      text: processed,
      annotations: { ruby: rubyData }
    };
  }
}
```

#### ステージ3: 注記除去（Annotation Removal）

```typescript
class AnnotationRemovalStage {
  private patterns = [
    // 傍点注記
    /［＃「[^」]+」に[^］]+］/g,
    /［＃[^］]*傍点[^］]*］/g,
    
    // 字下げ・字上げ注記
    /［＃ここから[^］]+］/g,
    /［＃ここで[^］]+］/g,
    /［＃[^］]*字[下上]げ[^］]*］/g,
    
    // 見出し注記
    /［＃[^］]*見出し[^］]*］/g,
    
    // 改ページ・改行注記
    /［＃改[ページ丁段行]］/g,
    
    // 外字注記
    /※［＃[^］]+］/g,
    
    // その他の注記
    /［＃[^］]+］/g,
    
    // 編集者注
    /〔[^〕]+〕/g
  ];
  
  process(text: string): string {
    let processed = text;
    
    // 保持すべき情報を抽出してから除去
    const annotations = this.extractAnnotations(text);
    
    // 注記を除去
    for (const pattern of this.patterns) {
      processed = processed.replace(pattern, '');
    }
    
    // 底本情報を除去（ファイル末尾）
    processed = this.removeBottomInfo(processed);
    
    return processed;
  }
  
  private removeBottomInfo(text: string): string {
    // 底本情報は通常「底本：」から始まる
    const bottomIndex = text.lastIndexOf('底本：');
    if (bottomIndex !== -1) {
      return text.substring(0, bottomIndex).trim();
    }
    return text;
  }
  
  private extractAnnotations(text: string): Annotation[] {
    // 将来的に傍点などの装飾情報を保持したい場合
    const annotations: Annotation[] = [];
    
    // 傍点情報の抽出
    const emphasisPattern = /［＃「([^」]+)」に傍点］/g;
    let match;
    while ((match = emphasisPattern.exec(text)) !== null) {
      annotations.push({
        type: 'emphasis',
        text: match[1],
        position: match.index
      });
    }
    
    return annotations;
  }
}
```

#### ステージ4: テキスト抽出（Text Extraction）

```typescript
class TextExtractionStage {
  process(text: string, config: ExtractionConfig): ExtractedText {
    // 本文の開始位置を特定
    const mainTextStart = this.findMainTextStart(text);
    const mainText = text.substring(mainTextStart);
    
    // 指定された長さの範囲を抽出
    const segments = this.extractSegments(mainText, config);
    
    return {
      segments,
      metadata: this.extractMetadata(text)
    };
  }
  
  private findMainTextStart(text: string): number {
    // タイトルや著者情報をスキップ
    // 通常、最初の段落または「　」（全角スペース）で始まる行が本文
    const lines = text.split('\n');
    
    for (let i = 0; i < lines.length; i++) {
      const line = lines[i].trim();
      
      // 空行をスキップ
      if (line.length === 0) continue;
      
      // 本文の開始パターン
      if (line.startsWith('　') || // 段落開始
          line.match(/^[「『（]/) || // 会話文
          line.match(/^第[一二三四五六七八九十百千万\d]+[章節話]/)) { // 章節
        return text.indexOf(lines[i]);
      }
    }
    
    return 0;
  }
  
  private extractSegments(text: string, config: ExtractionConfig): TextSegment[] {
    const segments: TextSegment[] = [];
    const { minLength, maxLength, preferSentenceBoundary } = config;
    
    if (preferSentenceBoundary) {
      // 文境界で区切る
      const sentences = this.splitBySentence(text);
      let currentSegment = '';
      
      for (const sentence of sentences) {
        if (currentSegment.length + sentence.length <= maxLength) {
          currentSegment += sentence;
        } else if (currentSegment.length >= minLength) {
          segments.push({
            text: currentSegment,
            startPos: 0,
            endPos: currentSegment.length
          });
          currentSegment = sentence;
        }
      }
      
      if (currentSegment.length >= minLength) {
        segments.push({
          text: currentSegment,
          startPos: 0,
          endPos: currentSegment.length
        });
      }
    } else {
      // 固定長で区切る
      for (let i = 0; i < text.length; i += maxLength) {
        const segment = text.substring(i, i + maxLength);
        if (segment.length >= minLength) {
          segments.push({
            text: segment,
            startPos: i,
            endPos: i + segment.length
          });
        }
      }
    }
    
    return segments;
  }
  
  private splitBySentence(text: string): string[] {
    // 日本語の文境界で分割
    return text.split(/([。！？!?]+)/g)
      .reduce((acc: string[], curr, i, arr) => {
        if (i % 2 === 0) {
          // 文章部分
          const sentence = curr + (arr[i + 1] || '');
          if (sentence.trim()) {
            acc.push(sentence);
          }
        }
        return acc;
      }, []);
  }
}
```

### 3.3 エラーハンドリング

```typescript
class ParserErrorHandler {
  handleError(error: Error, context: ParserContext): ParseResult {
    if (error instanceof EncodingError) {
      // 文字エンコーディングエラー
      return this.tryAlternativeEncoding(context);
    }
    
    if (error instanceof MalformedTextError) {
      // 不正な形式のテキスト
      return this.tryBestEffortParse(context);
    }
    
    if (error instanceof UnsupportedFormatError) {
      // サポートされていない形式
      return this.fallbackToPlainText(context);
    }
    
    throw error;
  }
  
  private tryAlternativeEncoding(context: ParserContext): ParseResult {
    // Shift-JIS, EUC-JPなどの代替エンコーディングを試す
    const encodings = ['UTF-8', 'Shift_JIS', 'EUC-JP'];
    
    for (const encoding of encodings) {
      try {
        const decoded = new TextDecoder(encoding).decode(context.rawData);
        return this.parseWithEncoding(decoded);
      } catch (e) {
        continue;
      }
    }
    
    throw new Error('Failed to decode text with any encoding');
  }
}
```

```typescript
class FullAozoraParser {
  private pipeline: ParserPipeline;
  private cache: ParserCache;
  private errorHandler: ErrorHandler;
  
  async parse(source: string | URL): Promise<RichDocument> {
    // キャッシュチェック
    const cached = await this.cache.get(source);
    if (cached) return cached;
    
    try {
      // 完全なパイプライン処理
      const result = await this.pipeline.process(source);
      
      // キャッシュに保存
      await this.cache.set(source, result);
      
      return result;
    } catch (error) {
      return this.errorHandler.handle(error, source);
    }
  }
}
```

## 6. パフォーマンス最適化

### 6.1 キャッシュ戦略

```typescript
class AozoraCache {
  private memory = new Map<string, CachedWork>();
  private storage = new IndexedDBAdapter();
  
  async get(workId: string): Promise<CachedWork | null> {
    // メモリキャッシュをチェック
    if (this.memory.has(workId)) {
      return this.memory.get(workId)!;
    }
    
    // IndexedDBをチェック
    const stored = await this.storage.get(workId);
    if (stored && !this.isExpired(stored)) {
      this.memory.set(workId, stored);
      return stored;
    }
    
    return null;
  }
  
  async set(workId: string, data: ParsedWork): Promise<void> {
    const cached: CachedWork = {
      ...data,
      cachedAt: Date.now(),
      expiresAt: Date.now() + (24 * 60 * 60 * 1000) // 24時間
    };
    
    this.memory.set(workId, cached);
    await this.storage.set(workId, cached);
  }
}
```

### 6.2 ストリーミング処理

```typescript
class StreamingParser {
  async *parseStream(stream: ReadableStream<Uint8Array>): AsyncGenerator<ParsedChunk> {
    const decoder = new TextDecoder('utf-8');
    const reader = stream.getReader();
    let buffer = '';
    
    while (true) {
      const { done, value } = await reader.read();
      
      if (done) {
        if (buffer) {
          yield this.parseChunk(buffer);
        }
        break;
      }
      
      buffer += decoder.decode(value, { stream: true });
      
      // 文境界で区切って処理
      const sentences = this.extractCompleteSentences(buffer);
      for (const sentence of sentences.complete) {
        yield this.parseChunk(sentence);
      }
      
      buffer = sentences.remaining;
    }
  }
}
```

# 青空文庫データ処理 — 選定原稿と既存保存の保護

2026-10-01 / 第2再設計。自動取り込みから直ちに遊べるv2の導線を休止し、問題は`Problem` v3へ分ける。既存IndexedDBの形式は更新しない。

## 遊べる原稿の正本

`src/data/passages.ts`の手作業で編集した3場面だけを使う。原文、作品、著者、本文URL、抜粋位置、場面名、短い導入、8〜12個の意味のまとまり、意味に関するヒント、編集意図を保持する。旧`fixedBooks.ts`の代替文章や未検証本文は使用しない。

選定原稿は`curatedVersion: 1`で明示する。`makeProblem`はこの原稿だけを受け入れ、`Problem.version: 3`を生成する。旧保存抜粋に印を足すだけの自動変換や、未選定データへの黙ったフォールバックはしない。

紙片の順次結合は、定義済みの比較用正規化後の原文と完全一致しなければならない。8〜12枚・空でない紙片・原文一致を開始時にも検査する。表示用の改行・空きマス・折り返しを解答へ混入させない。旧仮名・句読点・結合文字を勝手に書き換えない。

分割は人物・動作・情景などを読める長さで人が選ぶ。自然な別順序が多すぎる場合は、抜粋やまとまりを選び直す。文法エンジン、言語モデル、近似一致による採点は追加しない。ヒントも人が作成し、特定の継ぎ目を教えず、繰り返し閲覧できる。

原文と出典URLはデータとして保管するが、選択・組立中の画面や読み上げ用DOMに公開しない。完成後に元の原稿と出典を表示する。これはゲームの表示制御であり、クライアント配信データを暗号化して秘匿する仕組みではない。

## 既存保存は読み取り専用

IndexedDB `aozora-puzzle` / version 1 / `books`をそのまま残す。既存の`formatVersion: 2`および旧形式のレコードは、保存した本の一覧として読み取るだけで、削除・上書き・移行しない。`Problem` v3は遊ぶ問題の形式であり、保存DBのアップグレードを意味しない。

新規取り込み・再取り込み・保存済み抜粋からの出題は休止する。「人が場面と意味のまとまりを選んだ3場面に限定している」ことを明示する。保存済みの本を選んでも、別の選定場面へ黙って差し替えない。暗号化抜粋の復号や救済用の短文生成を復活させない。

## 休止中の取り込み処理

原典取得・整形・候補生成・保存ユーティリティは将来のために残すが、現行のゲーム導線から呼ばない。`AOZORA_API_BASE_URL`を設定しても取り込みを再開しない。再開や保存変更は別途設計・承認する。

既存処理の安全条件は保持する。青空文庫のHTTPS作品カードURLだけを受け付け、任意URLを代理取得しない。BOM・改行・ヘッダー/底本・ルビ・注記を扱い、Unicode番号のある外字は保持し、未解決外字では理由を示して中止する。別作品の代入や一般的な文字置換はしない。

既存の有限候補探索と`Intl.Segmenter`のsentence/wordによる自動分割は休止中の取り込み用であり、今回の3場面の編集・正誤判定には使わない。表示に必要なgrapheme処理は維持する。機械的条件を満たす候補と、人にとって良い問題を区別する。新たな言語解析基盤、移行処理、取得APIは追加しない。

## 検証方針

選定原稿だけの受け入れ、枚数と原文の往復一致、代表的なUnicode、入力元の制限を少数のNodeテストで確認する。実ブラウザでは保存一覧を開く前後のレコード非変更、休止理由の表示、旧原稿の非出題、完成前の原文・出典非表示を確認する。

原典照合と人による分割・ヒントの妥当性確認は、自動テストと区別して記録する。過去の取り込み・再取り込み成功記録は旧導線の履歴として保存し、現行の機能や検証結果とは扱わない。大量シード・全端末・外部取得の常時CIを追加しない。

# 青空文庫データ処理 — 選定原稿・音声・既存保存

2026-10-02。選定原稿は `curatedVersion: 1`、生成問題は `Problem` v3。新しい挑戦の保存は版付きlocalStorageであり、既存IndexedDBの更新ではない。

## 原文の正本

src/data/passages.tsの手作業で選んだ3作品・15問（4/7/4）のみを出題する。原文、出典、抜粋位置、意味の手掛かり、通常の分割、細かな分割、細かな単位ごとの発音指定を持つ。原文は青空文庫の連続した範囲から取り、別の箇所の継ぎ足しや表記の現代化をしない。

通常／細かな分割はそれぞれ比較用原文と完全一致し、通常の境界は細かな境界に包含される。4〜12片の検証範囲は機械的な目標数ではなく、意味と安全な音声の区切りを優先する。比較ではCRLF、段落頭字下げ、改行のみを既存ルールで処理し、句読点や仮名を置換しない。元データの改行・graphemeは紙面の表示へ残す。

発音指定は別の文字列で、例えば「宿酔」の表示を残したまま「ふつかよい」と読ませる。音声と既知の読みを照合して最細単位の境界を持ち、通常はその境界をまとめる。文字数比例で音声の位置を推定しない。原典照合、境界の安全性、試聴の自然さを混同しない。

## 音声配信

Irodoriの連続マスターを男女各1本／抜粋、GitHubのaudio-assetsへ置く。実在人物の模倣はせず、採用した合成音声を固定参照として使う。生成パラメータ、参照ハッシュ、ライセンスと透かし情報を最小限残す。モデルや生成キャッシュはコミットしない。

Vercelにはaudio-assetsを含めず、publicへのコピーやバンドルへのバイナリimportも行わない。時刻表だけをコードへ持ち、固定コミットのraw GitHub URLを一か所にまとめる。転送失敗・不正な範囲・安全未確認の切れ目は明示した視覚進行へ切り替え、誤った音声を代用しない。

## 保存と公開

Runの版付き保存を既知の原稿・紙片・提出結果へ照合する。盤面の重複ID、欠けた紙片、不正な出題順、消費や提出の不整合を拒否する。通常の中断からライフ・ヒントが戻らず、音声中の提出も一度だけ確定する。

元のIndexedDB `aozora-puzzle` / version 1 / `books` は読み取り専用。取り込み・再取り込み・保存済み本文からの出題は休止。削除、上書き、移行、復号、別の文章への差し替えは行わない。原典処理・取り込みユーティリティは休止中のまま残す。

原文・出典は挑戦終了まで画面・読み上げDOMへ公開しない。公開クライアントのデータや音声そのものを秘匿する仕組みではない。終了後に公開するのは今回挑戦した抜粋で、未出題まで振り返りへ並べない。

少数のNodeテストと型・lint・ビルド、代表操作で確認し、原典ネットワーク照合や全音声試聴を恒常CIへ載せない。実行した確認と未確認点はDraft PRへ簡潔に残す。

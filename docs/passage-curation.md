# 短い抜粋と二つの分割

『吾輩は猫である』4問、『檸檬』7問、『銀河鉄道の夜』4問の計15問を維持する。朗読20〜25秒を暫定の目安とし、字数上限にはしない。意味がひとまとまりになり、情景や読んだ記憶から原文の並びを考えられることを優先する。短い場面を水増しせず、長めでも切ると意味が弱くなる場面は残す。

「ふつう」と「むずかしい」は同じ原文を使う。ふつうは大きな意味のまとまり、むずかしいはその内部の節・話題・句点をさらに分ける。枚数をそろえるために助詞や名詞句を細切れにしない。朗読の自然な区切りも優先し、初案の8〜10片から6〜9片へ調整した。通常も、構造と朗読の自然な間に合わせて4片または5片とする。意味だけでは入れ替えられる描写も、原作の記憶を手掛かりにできるため、すべて排除しようとはしない。

## 原文・読み・音声の対応

- 出典は青空文庫の[吾輩は猫である](https://www.aozora.gr.jp/cards/000148/files/789_14547.html)、[檸檬](https://www.aozora.gr.jp/cards/000074/files/424_19826.html)、[銀河鉄道の夜](https://www.aozora.gr.jp/cards/000081/files/456_15050.html)。抜粋はそれぞれ連続した箇所で、別の位置を継ぎ足さない
- 表示用原文は旧表記・句読点を保持する。本の城にまたがる改段落も残す。`comparisonText` は改行と段落頭の字下げだけを除く
- `hardFragments` は細かい分割、`fragments` はその連続する片をまとめた通常の分割。両者を結合すると同じ比較用原文になる
- `speechReadings` は細かい分割に一対一で対応するかなの読み。宿酔→ふつかよい、掌の裏→てのひらのうち、盤面→ダイアルなどを原文とは別に持つ
- `audio-assets/requests.json` の `fragments` は原文と読みの対、`normalGroups` は0始まりの連続インデックス、`speechFragments` は対応する実際の音声入力。`speechFragments` の結合は `speechText` と完全一致する
- 各片の原文範囲は、手前の片の文字数の累積から一意に求められる。改段落込みの表示位置、かなの字数、再生時刻を同じものとして扱わない
- 話題・節の自然な間だけを音声入力へ補い、名詞句の途中へ機械的に読点を追加しない。両難易度は同じ連続マスターとその時刻表を使い、通常の境界は細かい境界の部分集合にする
- 抜粋・境界・読みを変える場合は、原文フィクスチャ、音声リクエスト、男女の時刻表を合わせて更新する。旧IDの長い抜粋へ音声だけを流用しない

出典照合・原文往復一致・集約対応は少数のオフラインテストで守る。文章の面白さ、声の自然さ、実際の停止境界の聴感は機械検査とは別に確認する。

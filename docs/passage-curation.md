# 抜粋の選定理由

『吾輩は猫である』4問、『檸檬』7問、『銀河鉄道の夜』4問の計15問。既存12問の原文・分割・手掛かりは維持した。

既存の『檸檬』4問は本文の約52〜91%に集中し、前半が欠けていた。他の2作品は冒頭〜前半の抜粋なので、全作品を一律に入れ替えず、『檸檬』に次の3問を加えた。問数や作品の三等分を機械的にそろえる方針にはしない。

- 冒頭の不吉な塊（298字・11片）：第一段落全体。心の重圧から街をさまよう姿までを残し、後の檸檬による軽さとの対照にする
- 見すぼらしくて美しい街（245字・9片）：第二段落全体。裏通りと植物の生命力を、表裏・衰えと美しさの対比から読める
- 花火とびいどろの記憶（348字・12片）：連続する第四・第五段落。色から味覚、幼い記憶へ進むまとまりと内部の改段落を残す

青空文庫の[『檸檬』本文](https://www.aozora.gr.jp/cards/000074/files/424_19826.html)からの連続抜粋。旧仮名・語句・句読点を変えず、別箇所の継ぎ足しはしない。街の冒頭は語り手と美の対象を一片にまとめ、並列する植物・花火名も個別に切らないことで、不自然に交換できる分割を避けた。

出典と抜粋位置は各原稿データに保持する。原文一致は小さなNodeテストで守り、人間の読みやすさ・難しさ・面白さと自動検査の成功は区別する。検証結果はPRの説明へ簡潔にまとめ、スクリーンショットやログをリポジトリに蓄積しない。
